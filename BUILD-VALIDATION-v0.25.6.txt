Huymaier Console v0.25.6 build validation

Static validation performed in the build environment:
- PowerShell and C# delimiter/lexical scan.
- JSON and AppX XML parsing.
- Choice-popup state is explicitly initialized before StrictMode reads it.
- Quick Access location, keyboard theme, prompt override, music theme, and display scale are routed through the centered chooser.
- Display scale range is constrained to 100%-500%; Windows account DPI values are written under HKCU and sign-out is surfaced when effective/configured scale differs.
- Release/package checksum manifests regenerated after all changes.

Windows runtime validation still required on a Windows 11 target for WPF/native compilation and live DPI behavior.
