Huymaier Console v0.24.8
PS2 Boot Skyline, Save Icon Rendering and Global Controller Hot-Plug Fix

GLOBAL CONTROLLER STABILITY
- Debounces the multi-event Windows arrival/removal burst produced by one controller connection.
- Suspends shell navigation briefly, then rebuilds the native input router once after devices settle.
- Xbox/XInput device changes no longer invalidate the Sony Raw HID cache.
- Applies globally on Home, Games, Apps, Settings, PS2 and PS3—not only inside an emulator view.
- Preserves current Home-screen focus rather than closing/replacing the active console surface.

PLAYSTATION 2 BOOT SEQUENCE
- Adds a native, skippable PlayStation 2 boot presentation.
- Cross/A or Enter skips; directional input is ignored until the sequence completes.
- Imported PS2 startup audio determines the animation duration when its media length is available.
- When the startup sound ends, the boot presentation transitions into looping menu ambience.
- A new Full PS2 Boot Animation setting can disable the visual sequence without removing audio choices.
- The dense boot flythrough uses solid blue-violet saved-data monoliths, central depth, fog, glow and colored particle streaks.
- The live PS2 menu uses a calmer, sparser version so text and navigation remain readable.

PS2 MEMORY-CARD ICONS
- Corrects the PS2-to-WPF coordinate conversion that mirrored and inverted save models.
- Removes per-triangle wireframe outlines.
- Parses per-vertex UV coordinates and decodes the embedded 128x128 A1B5G5R5 texture.
- Supports raw and RLE-compressed icon texture streams.
- Depth-sorts solid icon triangles and applies texture/color sampling with simple face lighting.
- Retains animated shape interpolation and the native PS2-style save browser/actions from v0.24.7.

PRESERVED FROM v0.24.7
- PCSX2 Big Picture launch for every PS2 game.
- Only Cross/A or Enter starts a game; D-pad Down never launches.
- Native card/save browsing, details, copy, backup, export and recoverable delete.
- Readable PCSX2 option names.
- Huymaier Console foreground/focus restoration after PCSX2 or RPCS3 closes.
- PS2 startup/menu/game-selection audio and PS3 Home Menu ambience sequence.

REFERENCE / ASSET POLICY
- PS2IODB was used as a technical behavior/format reference; no PS2IODB database assets are bundled.
- The user-provided Shadertoy shader and captures were used as visual references; the WPF renderer is an independent implementation.
- No Sony BIOS, firmware, copyrighted startup media or save icons are included.
