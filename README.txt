HUYMAIER CONSOLE FSE v0.25.6

Controller-first Windows 11 full-screen console shell.

This stabilization build adds reliable centered option choosers for Quick Access location, keyboard theme, button prompts, music theme, and Windows display scale. Display Scale is under Settings -> Display and uses percentage choices from 100% through 500%; Windows sign-out is surfaced when required for the new account scale to apply fully.

It also preserves the v0.25.5 clean-install startup fix, Epic/Legendary live transfer telemetry, 7-day / 20-entry download history, dedicated Windows Update and Driver Update pages, GitHub self-update, Steam population, RPCS3 users, and shared Shelf/Library artwork.

Install
1. Extract the ZIP to a normal local folder such as C:\HC256.
2. Run Install-HuymaierConsole.cmd.
3. Launch Huymaier Console from the installed shortcut.

See RELEASE_NOTES-v0.25.6.txt and Docs\TEST-CHECKLIST.txt.
