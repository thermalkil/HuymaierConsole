Huymaier Console v0.24.21
Xbox Dashboard Rebuild + PlayStation Music Player

ORIGINAL XBOX
- Replaces the shared placeholder shell with a dedicated 5960-era green-orb presentation.
- Adds separate Games, Memory, Music, Xbox Live, and Settings areas.
- Detects an optional separately installed UIX Desktop / Theseus executable and can launch it from Settings.
- xemu remains the primary game backend with Cxbx-Reloaded fallback.

XBOX 360
- Dashboard choices are now Blades and Metro only; NXE is removed and migrated to Blades.
- Blades uses dedicated blade tabs, era-oriented panel geometry, and Media/System sections.
- Metro uses separate Games, Apps, Music, Video, Social, Bing, and Settings tabs.
- Adds an Xbox Guide overlay and keeps the louder dashboard music/navigation defaults.
- Xenia Canary remains primary with Xenia Master fallback.

PLAYSTATION MUSIC PLAYER
- CD-audio track files no longer appear as standalone games.
- CUE sheets are parsed for AUDIO tracks and grouped into an album named after the matching game.
- Albums reuse the corresponding DuckStation game cover.
- Separate-file and indexed raw BIN audio tracks are prepared as cached 44.1 kHz stereo WAV files.
- Includes album browsing, play/pause, previous/next track, stop, and automatic next-track playback.

PLAYSTATION NAVIGATION
- Up and Down now use the real card footprint and remain in the same visible column.
- An incomplete final row no longer clamps focus diagonally to its last game.

PRESERVED
- User-supplied startup videos and 4K playback copies.
- PS1 Original/Updated shells and DuckStation cover import.
- Existing PS2 and PS3 native integrations.
- Cache-first library opening and explicit-only provider/artwork refresh behavior.

INSTALL
Extract to C:\HC2419 and run Install-HuymaierConsole.cmd.
