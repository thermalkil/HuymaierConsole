Huymaier Console v0.24.4
PlayStation 2 Interface and PCSX2 Launch Fix

FIXED
- Removes the forced PCSX2 -datapath argument that caused the reported "unknown error -datapath" launch failure.
- Launches games with the current PCSX2 command-line form: -batch -fullscreen -- "game path".
- Reports immediate PCSX2 failures with the process exit code instead of silently returning.
- Opens the normal PCSX2 desktop interface without injecting a data-path override.

PLAYSTATION 2 INTERFACE
- Keeps the broadband-navigator-inspired top menu while branding it PlayStation 2 throughout.
- Removes doubled glow text and overlapping menu subtitles.
- Replaces the oversized solid save towers with sparse, small, wireframe saved-data structures and a restrained blue data cloud.
- Rebuilds Game Channel around Collection / Disc navigation and a perspective cover flow using existing PCSX2 covers.
- Adds a separate base-PS2 Browser presentation for memory cards, saved-data entries and card operations.

LIBRARY
- Loads the last successful PS2 game cache immediately and refreshes configured PCSX2 game folders in the background.
- Preserves serial extraction and reuse of PCSX2 cover downloads.

PRESERVED
- Keeps the v0.24.1 PS3 firmware-theme/custom-color work and stable v0.23.8 controller, GOG, shelf-art and save fixes.
