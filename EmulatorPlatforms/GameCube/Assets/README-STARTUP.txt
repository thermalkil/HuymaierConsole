Startup video files

Startup.original.mp4 preserves the user-supplied source without modification.
Startup.mp4 is the Windows-compatible playback copy using H.264 video and AAC audio.
Startup.fallback.mp4, when present, is an automatic 1080p fallback used only if the 4K playback copy cannot be opened.

These files are used only by the matching native Huymaier Console platform shell.
