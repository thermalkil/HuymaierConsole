The default PlayStation 2 interface uses original Huymaier-rendered visuals modeled
after the PlayStation Broadband Navigator presentation. No Sony firmware, BIOS,
PSBBN binaries, icons, sounds, or proprietary artwork are bundled.

The built-in saved-data geometry is generated locally and read-only from the user's
PCSX2 memory cards. It is not copied from Sony assets and never modifies card data.

In Settings > Interface Assets, select a personal PS2 asset folder. Supported optional
files include background.png/jpg and logo.png/jpg.
