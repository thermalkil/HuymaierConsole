Huymaier Console v0.24.23
Xbox Cover Art / Blades Reconstruction / RPCS3 Portable Users

WHAT CHANGED

PS3 — RPCS3 USERS
- Fixed profile discovery for portable RPCS3 installations such as:
  Y:\Emulators\PS3\dev_hdd0\home\00000001\localusername
  Y:\Emulators\PS3\dev_hdd0\home\00000002\localusername
- The XMB now scans every valid eight-digit directory under dev_hdd0\home.
- localusername supplies the friendly display name when available.
- A valid profile folder is no longer discarded just because localusername is missing/unreadable.
- User discovery checks the directory beside rpcs3.exe, the configured RPCS3 data path, the resolved data root, and standard AppData roots.
- PS3 Saved Data Utility and Trophy Collection now follow the same physical profile root that supplied the selected user.
- Selected profile remains the RPCS3 --user-id used for game boot and RPCS3 UI launch.

ORIGINAL XBOX / XBOX 360 — ONLINE COVER ART
- Xbox-family libraries now automatically look for missing box art after the native dashboard opens.
- Uses the public Libretro Microsoft - Xbox and Microsoft - Xbox 360 Named_Boxarts repositories.
- Covers are downloaded once to the platform-local Artwork\BoxArt cache and persisted in library-cache.json.
- Local sidecar/covers-folder artwork still takes priority.
- Added Settings > Refresh Online Cover Art for an explicit retry.
- Both Original Xbox and Xbox 360 Games views are now cover-art-first rather than text-list-first.

XBOX 360 BLADES
- Replaced the oversized colored-column interpretation from v0.24.22.
- Blades now use a compact stack of silver blade edges with generation-specific colored accents.
- Only the active blade owns the colored content pane.
- Added period-style profile/Gamerscore chrome and compact menu separators.
- Games are presented as real cover tiles inside the Games blade.
- Blades/Metro switching remains in-place and Metro behavior from v0.24.22 is preserved.

VALIDATION NOTE
This package was structurally validated in the build environment, but the native WPF assembly cannot be compiled or exercised here. Treat v0.24.23 as a Windows test candidate until it passes the included checklist.
