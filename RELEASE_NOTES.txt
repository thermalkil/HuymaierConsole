Huymaier Console v0.26.3 RC3 — Authentic Console Interfaces, Emulator Setup & Artwork Reliability

Changes
- Rebuilds Nintendo 64 around an original cartridge-console presentation inspired by the supplied classic-mini reference instead of inventing a generic BIOS/dashboard.
- Replaces the flat GameCube approximation with a translucent animated 3D IPL-style cube. Game Play, Calendar, Memory Card, and Options are cube faces and navigation rotates the cube to the selected face.
- Refines Wii and Wii U toward their real channel/software interfaces and keeps emulator/library/data management inside those visual languages rather than opening generic console settings pages.
- Removes fake/nonfunctional service entries such as Wii/Switch news-style placeholders and keeps only functionality Huymaier Console can actually execute.
- Keeps N64, GameCube, Wii, Wii U, Switch, Original Xbox, and Xbox 360 navigation spatial and local; LB/RB are not normal page/selection controls.
- Routes emulator executable, data/cache, game-library folder, ambience, and supported save-export destinations through Huymaier Console's controller-first native file browser.
- If an emulator is not attached, native console settings can locate an existing installation or install the latest supported upstream release.
- Removes the previously assumed/default Dolphin Documents paths; Dolphin data is taken from the configured Huymaier data path or a portable User folder beside the selected executable.
- Console cover art resolves emulator-provided/local cache art first, Huymaier cache second, and online console artwork only after those sources. User game/ROM files are never renamed or moved for artwork.
- Steam installed and owned-library entries no longer intentionally carry a blank cover: local Steam library/grid artwork is preferred, then Steam-hosted portrait artwork is cached, then a deterministic cached fallback is generated if Steam artwork cannot be retrieved.
- PS1, PS2, and PS3 visual/navigation implementations remain frozen from the v0.26.2 baseline; only emulator/data/library path and install handoff is integrated with the shared Huymaier picker.
- Preserves the approved v0.26.2 Game Bar/Guide behavior and inherited release-blocking regression coverage.

Testing focus
1. N64: verify cartridge carousel flow, utility/settings access, launch/return, and no generic tab UI.
2. GameCube: verify the translucent 3D cube visibly rotates between all four faces and A/B navigation remains layered and predictable.
3. Wii/Wii U/Switch/Xbox surfaces: verify only functional actions remain and settings look native to the current console.
4. Every emulator: locate executable/data/game folders using Huymaier's file browser; test Install Latest on a platform with no configured emulator.
5. Steam: refresh installed and owned library and confirm every title has a usable ArtworkPath even when local Steam library art is absent.
6. Console art: confirm emulator-provided cover/cache files win over online artwork.
7. Guide/Home and Huymaier Game Bar behavior must match the approved v0.26.2 release exactly.
