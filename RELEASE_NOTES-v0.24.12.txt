Huymaier Console v0.24.12

MAIN CONSOLE ARTWORK AND LIBRARY
- Normal startup, shelf opening and Library opening now use the saved game index and persisted cover paths immediately.
- No provider scan or online-artwork worker starts merely because the user opens a page or reconnects a controller.
- Artwork is refreshed only after an explicit library rescan, provider refresh, library-location change, newly imported title, or manual artwork refresh.
- Shelves and Library now resolve the same cover-art record instead of maintaining separate fragile shelf artwork state.
- Shelf cards are large 2:3 portrait box-art cards rather than small landscape icons.
- Platform Library cards are created in bounded batches; cached images are decoded separately so the page header appears immediately.

PLAYSTATION 1 PLATFORM
- Adds a native in-process PlayStation interface with Games, Memory Cards, Save States and Settings sections.
- Detects installed DuckStation executables and standard, legacy Documents, or portable data folders.
- Offers an optional managed portable DuckStation install to a user-selected external folder.
- Reads DuckStation game folders, reuses existing cover art, caches the library, groups multi-disc games, and provides a # through Z jump index.
- Launches games with DuckStation batch, Big Picture and fullscreen arguments and returns to the PlayStation main menu in true fullscreen.
- Includes a skippable native PlayStation-inspired boot presentation and user-importable startup/menu audio.
- Adds BIOS validation/import and readable settings.
- Adds a native PS1 memory-card browser with save icons, details, export, backup, recoverable delete, copy between cards, duplicate card and create card.
- Adds DuckStation save-state browsing, load, export and recoverable delete.

PRESERVED
- v0.24.11 PS2 memory-card icon orientation and textures.
- PS2/PS3 launch-return, fullscreen recovery, audio and controller handling.
- Global Xbox and PlayStation controller hot-plug stabilization.

DuckStation, BIOS files, PlayStation games, system audio and copyrighted Sony assets are not included.
