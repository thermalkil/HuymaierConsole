# Huymaier Console v0.30.7

This release expands the console-only **Edit Model** lighting editor into a full lightweight studio spotlight while preserving the existing provider/storefront presentation exactly as-is.

## Advanced per-console lighting

Each console model can now save its own:

- Overall model lighting from **20% to 400%**
- Studio light brightness from **0% to 500%**
- Light azimuth with **1-degree** control
- Light elevation from **-89° to +89°** with 1-degree control
- Light distance from **1.0 to 20.0**
- Light aim X / Y
- Spotlight cone size from **5° to 180°**
- Cone softness
- Distance falloff
- Color temperature from **1800K to 12000K**
- Ambient level up to **300%**
- Specular strength up to **400%**
- Highlight size from **25% to 400%**

All values update live in Edit Model and persist independently per console.

The spotlight is analytic and does **not** add shadow maps or another shadow rendering pass, keeping the feature inexpensive enough for shelf and fullscreen presentation.

## Provider/storefront isolation

The top Providers models are intentionally unchanged. Steam, Epic, GOG, EA, Ubisoft, Recomps, Xbox PC and the other storefront/provider models continue through the exact legacy showroom-lighting path and do not receive the console presentation overrides.

## Carried forward

v0.30.7 also retains the complete v0.30.6 console model editor, including rotation, roll, scale, position, mirroring, face mode, lighting and fan motion; the mirrored/inside-out geometry corrections; HC3D v4 vertex-color/material support; Windows/Xbox FSE updater handoff; controller/Guide behavior; Downloads; GameCube; Recomps; streaming; unified cursor; and installer/integrity protections.
