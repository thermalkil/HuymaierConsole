# Huymaier Console v0.26.1

This release hardens Huymaier Console's installer, updater, native controller routing, storefront identity handling, and customization layer while promoting the exact RC19 package that passed the Windows release-shaped validation pipeline.

## Highlights

- Adds transactional install/update behavior with a persistent incomplete-install marker and verified rollback.
- Skips unchanged managed files by hash, preventing locked-but-identical files such as the console icon from breaking upgrades.
- Adds exact package SHA-256 verification and a closed internal checksum manifest.
- Adds fail-closed startup when the installed manifest or native payload is inconsistent.
- Builds and validates the x64 Huymaier Console executable, x64 GameInput bridge, and x64 FSE host in Windows CI.
- Improves Xbox/Guide/Home routing with a dedicated Guide-only background wake path that does not consume normal D-pad/A/B/shoulder navigation.
- Keeps Xbox PC storefront identity separate from Original Xbox and Xbox 360 emulator identities.
- Repairs storefront library-location importing through the native controller-first file browser.
- Improves Huymaier Game Bar foreground handling for external applications and adds modal Huymaier controller ownership while the overlay is visible.
- Adds Settings → Customization with console display-name branding, interface/accent/focus colors, dynamic-theme palettes, music settings, navigation sound settings, and keyboard appearance controls.
- Improves selected-card rendering and removes stray native WPF focus outlines.
- Preserves existing user data and unmanaged library configuration across repairs and upgrades.

## Installer and updater integrity

- The updater requires the published `HC261.zip.sha256` sidecar and verifies the archive before extraction.
- ZIP paths are validated before extraction.
- Package PowerShell is parsed before any managed payload is replaced.
- Failed repair/update transactions retain the incomplete-install marker unless rollback is verified.
- Duplicate Console launches are blocked by the native single-instance gate.
- Legacy Xbox Game Bar controller-setting backups remain migratable and are restored safely.
