# Huymaier Console v0.30.4

This release is the first public update intended to verify the repaired v0.30.3 Windows/Xbox Full Screen Experience updater path end to end, and it adds in-console correction of 3D model orientation.

## 3D model editing

- Adds **Edit Model** to the full-screen 3D model viewer.
- Press **X / Square** while viewing a model to enter the orientation editor.
- Use the **left stick or D-pad** to rotate the model horizontally and vertically.
- Press **A / Cross** to save the current orientation as that model's default.
- Press **Y / Triangle** to reset that model to the original default orientation.
- Press **B / Circle** to cancel an edit without changing the saved default.
- Saved orientation is stored per GLB filename in Huymaier Console configuration; the user's GLB file is never modified.
- Saved orientation is applied to both the Games shelf and full-screen viewer, and the bounded fan animation moves around the saved default orientation.
- Removes shelf-index-derived rotation so a model's saved default no longer changes when platform/provider ordering changes.

## FSE updater verification

- Carries forward the v0.30.3 FSE update handoff unchanged.
- Systems already on v0.30.3 can use **v0.30.4 as the first real in-FSE updater test**: start the update from Huymaier Console while remaining in Full Screen Experience mode and allow the Console to close, install, and relaunch through the FSE host.
- Desktop-mode updater behavior remains supported.

## Carried forward

- Overall Huymaier Console brightness control from 0% to 200% in exact 10% increments.
- 3D-model brightness from 0% to 200% and bounded fan-style idle motion.
- HC3D v4 / glTF COLOR_0 rendering fixes.
- Controller navigation, Quick Access, Downloads, Recomps, GameCube, streaming, provider integrations, and installer integrity protections.
