# Huymaier Console v0.26.0

This release introduces the native Huymaier Game Bar and task switcher while keeping Quick Access exclusive to Huymaier Console itself.

## Highlights

- Adds the centered native Huymaier Game Bar for external games and apps.
- Adds a native controller-first task switcher with application preview cards.
- Routes the physical Xbox/PS/Guide/Home system button separately from Xbox View/Back and PlayStation Share/Create.
- Uses Microsoft GameInput only as the low-level system-button backend, with Raw HID/XInput compatibility fallback.
- Suppresses Xbox Game Bar controller activation while Huymaier Game Bar is enabled.
- Adds DPI-aware Game Bar sizing and a user-adjustable 70–140% Game Bar scale setting.
- Uses Left/Right navigation on horizontal Home and Switch Apps rails, with Up/Down retained for vertical pages.
- Preserves maximized/fullscreen application state when switching back to games such as RPCS3.
- Repairs finite-choice Settings popups with direct controller command routing, visible gold selection state, a moving selection marker, and working navigation audio.
- Prevents popup feedback failures from interrupting selection movement or repainting.
- Removes controller prompts for unavailable secondary actions.

## Compatibility and packaging

- Built on the stable v0.25.8 runtime/media package.
- Preserves Windows PowerShell 5.1 UTF-8 BOM packaging requirements.
- Preserves the updater ContentLength compatibility fixes from v0.25.8.

The v0.26.0 runtime candidate passed Windows PowerShell parsing, native GameInput bridge compilation, full managed application compilation, package generation, and final Windows controller runtime testing before release.
