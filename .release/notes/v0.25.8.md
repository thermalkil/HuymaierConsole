# Huymaier Console v0.25.8

Windows PowerShell 5.1 packaging hotfix.

- Restores UTF-8 BOM encoding on packaged PowerShell source so Windows PowerShell 5.1 reads non-ASCII UI glyphs correctly.
- Fixes the v0.25.7 installer parser failure caused by UTF-8-without-BOM source produced by the Linux release pipeline.
- Preserves the GitHub updater download fix that treats `ContentLength` as a scalar rather than using `.HasValue`.
- Preserves the v0.25.6 centered Settings choice popups, Display Scale setting, fresh-PC startup fix, Epic/Legendary live telemetry, and prior stabilization work.
