# Huymaier Console v0.30.3

This is a focused updater reliability release for Windows/Xbox Full Screen Experience mode.

## Fixed

- Prevents the Full Screen Experience home host from immediately relaunching the old Huymaier Console runtime while an in-app update is replacing files.
- The FSE host now remains alive during the update handoff, waits for the external updater to finish, then launches the newly installed Huymaier Console build.
- The updater automatically detects when it is running under the Huymaier FSE host through an inherited environment marker and coordinates the handoff with a bounded lock file.
- Desktop-mode self-update behavior remains unchanged and continues to use the updater-owned relaunch path.

## Carried forward

- Overall Huymaier Console brightness control from 0% to 200% in exact 10% increments.
- 3D-model brightness from 0% to 200% and bounded fan-style idle motion.
- HC3D v4 / glTF COLOR_0 rendering fixes, controller navigation, Quick Access, Downloads, Recomps, GameCube, streaming, provider integrations, and installer integrity protections.

## Important one-time upgrade note

Systems currently running v0.30.2 do not yet contain this FSE host handoff fix. Upgrade from v0.30.2 to v0.30.3 once from Windows desktop mode or by manually installing this release. After v0.30.3 is installed, a later update can be used to verify the repaired in-console update flow while remaining in Full Screen Experience mode.
