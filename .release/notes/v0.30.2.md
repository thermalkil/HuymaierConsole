# Huymaier Console v0.30.2

v0.30.2 is intentionally a focused follow-up release for validating the repaired in-console updater from v0.30.1.

## New

- Adds **Huymaier Console brightness** under **Settings → Customization**.
- Brightness range is **0%–200%**.
- Left/right adjustment is locked to exact **10% intervals**.
- Default brightness is **100%**.
- The setting is persisted between launches.
- This changes Huymaier Console's interface presentation only; it does not change Windows display brightness or external applications.

## Carried forward from v0.30.1

- Repaired in-console update version ordering for the new public version line.
- Verified update ZIP + SHA-256 download and transactional self-update handoff.
- 0%–200% 3D-model brightness control.
- Bounded fan-style 3D shelf motion instead of continuous 360° rotation.
- HC3D v4 / COLOR_0 model color support and the validated controller, Quick Access, Downloads, Recomps, GameCube, streaming, installer and platform behavior.

This is a normal public GitHub Release so an installed v0.30.1 system can discover, download, install and relaunch into v0.30.2 entirely through Huymaier Console.
