# Huymaier Console v0.3.0

v0.3.0 is the new public-version baseline for Huymaier Console. It promotes the exact RC11 package that passed the Windows release-shaped validation pipeline and the final real-PC platform-model color test.

## Highlights

- Promotes the accumulated v0.26.3-v0.26.5 development line into a clean public v0.3.0 baseline.
- Adds and stabilizes native 3D provider/platform shelves across the Games experience.
- Fixes glTF vertex-color rendering end-to-end with HC3D v4, restoring authored colors such as GOG purple instead of washed-out white/gray models.
- Preserves textured, base-color-factor, mirrored-winding, alpha, material-map, UV, brightness, naming, and shared D3D11 shelf-rendering behavior.
- Preserves the unified cursor, native GameCube work, streaming work, controller/Guide routing, Quick Access behavior, provider integrations, Downloads/history behavior, Recomps, installer integrity, and native emulator surfaces.
- Keeps the exact validated package bytes from RC11 rather than rebuilding a different release payload.
