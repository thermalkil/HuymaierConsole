# Huymaier Console v0.25.6

## Settings chooser + Windows scale stabilization

- Fixes the centered choice-popup system under PowerShell StrictMode by explicitly initializing popup state before first use.
- Quick Access Location now reliably opens a centered **Bottom / Top / Left / Right** chooser.
- Keyboard Theme now opens a centered **Huymaier / Light / High Contrast** chooser instead of using the old cycle action.
- Button Prompts now use a centered **Auto / Xbox / PlayStation / Nintendo / Steam / Keyboard** chooser.
- Music Theme now uses the same centered chooser and only offers Custom when a custom music file is configured.
- Adds **Settings → Display → Scale** with percentage choices from 100% through 500%.
- Display Scale writes the Windows account DPI scale and clearly reports when sign-out is required for the selected scale to apply fully.
- Adds a controller-friendly **Sign out to apply display scale** action with confirmation when a new scale is pending.
- Preserves the v0.25.5 fresh-PC empty-collection startup fix and richer fatal startup diagnostics.
- Preserves Epic/Legendary live download telemetry, seven-day / twenty-entry download history, GitHub self-update, Windows Update, Driver Updates, Steam population, RPCS3 users, and shared Shelf/Library artwork.

## Testing focus

1. Quick Access Location and Keyboard Theme should both open centered popup menus.
2. Button Prompts and Music Theme should use the same chooser behavior.
3. Display → Scale should open the percentage chooser and report pending scale until Windows sign-out.
4. A fresh/empty Huymaier Console profile should still boot without the previous `.Count` failure.
5. Existing v0.25.5 systems should detect this release through **Settings → Updates → Huymaier Console Update**.
