# Huymaier Console v0.26.2

This release promotes the exact RC4 package that passed the Windows release-shaped validation pipeline and the final real-PC Game Bar test. It builds on the frozen v0.26.1 installer/integrity baseline while improving native-console Guide routing, controller-first customization, Games layout control, Steam management/counting, and provider download progress.

## Highlights

- Fixes Guide/Home routing over Huymaier-native console surfaces: the main Huymaier shell still opens Quick Access, while PS3/PS2/Original Xbox/Xbox 360/native console surfaces and external applications open the Huymaier Game Bar.
- Preserves modal/topmost Game Bar controller ownership so underlying Huymaier navigation does not consume the same input.
- Adds a controller-first visual color picker for editable interface/theme colors without requiring hex entry.
- Adds Games layout customization with controller-driven reorder, hide/show, size presets, show-all, and reset behavior.
- Fixes shared action-card title clipping.
- Improves Steam owned/installed counts and supports controller-first install, uninstall, validate, and launch actions through Steam.
- Adds ownership-aware Steam library merging with honest fallback when Steam profile ownership data is private or unavailable.
- Adds real provider progress/state plumbing for Steam plus observed provider progress adapters for supported storefront workflows.
- Preserves the fixed storefront/native folder-picker importing behavior from v0.26.1.
- Preserves transactional installer/update integrity, exact SHA-256 verification, x64 native payload validation, rollback safety, and unmanaged user-data preservation.
