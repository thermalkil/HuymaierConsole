# Huymaier Console v0.25.7

Self-update download compatibility hotfix.

## Fix

- Fixes the Huymaier Console Update download action failing with `The property 'HasValue' cannot be found on this object` on Windows PowerShell 5.1.
- Treats `HttpClient` Content-Length as the scalar `Int64` value PowerShell exposes instead of assuming `Nullable<Int64>.HasValue` / `.Value`.

- GitHub release detection, live update download progress, SHA-256 verification, staged installation, and automatic relaunch.
- v0.25.6 centered Settings choice popups and Windows Display Scale integration.
- v0.25.5 clean-install startup stabilization.
- Epic/Legendary live transfer telemetry and 7-day / 20-entry completed download history.
