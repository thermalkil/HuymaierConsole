Huymaier Console v0.24.26 — Native Driver Management

NEW: SETTINGS > DRIVERS & HARDWARE
- Adds a controller-first native driver-management page to Huymaier Console Settings.
- Detects installed signed Plug and Play drivers through Windows driver inventory.
- Promotes installed graphics adapters to the top of the page with vendor, driver version, and driver date.
- Scans the configured Windows Update service specifically for applicable Type='Driver' updates rather than mixing drivers into the normal software-update list.
- Installs recommended Windows driver updates from inside Huymaier Console. Installation uses the Windows Update Agent and requests administrator approval only when installation begins.
- Driver results can include graphics, chipset/system, audio, network, Bluetooth, storage, USB, and other Plug and Play device classes offered by Windows Update.
- Shows reboot-required state in the native page and offers the existing controller-friendly restart confirmation.

LOCAL / OEM DRIVER PACKAGES
- Adds Install local driver package from the native driver page.
- Reuses Huymaier Console's own controller-first folder picker; no Windows Open dialog is required.
- Recursively discovers .inf packages in the selected folder.
- Installs/updates matching devices with Windows PnPUtil using /add-driver, /subdirs, and /install.
- Windows driver-signing policy remains authoritative; Huymaier Console does not bypass signature enforcement.
- PnPUtil output/errors are captured into driver-state.json for display/diagnostics.

SAFETY / ARCHITECTURE
- Normal software Windows Update remains separate under Downloads > Windows Update.
- Driver scans run in a background worker so Settings navigation remains responsive.
- Driver installation is elevated only for the install operation.
- Huymaier Console respects the machine's configured Windows Update/Microsoft Update policy and does not replace the Windows driver store.
- This build does not silently uninstall or force-replace drivers and does not bypass Windows compatibility/signature checks.

PRESERVED FROM v0.24.25 / v0.24.24
- PS3 RPCS3 user discovery/selection remains working.
- Steam games remain populated natively in Library and Shelf.
- Shelf artwork continues to use the same resolved artwork as Library.
- Xbox/Xbox 360 and PS3 native-dashboard crash containment remains enabled.
- Xbox/Xbox 360 cover-art caching, Xbox 360 Metro/Blades switching, achievements/save management, PS3 themes, and console-count reconciliation remain in place.

TEST CANDIDATE
- The Windows installer still performs native C# compilation on the target PC.
