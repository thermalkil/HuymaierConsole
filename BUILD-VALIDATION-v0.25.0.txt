Huymaier Console v0.25.0 build validation

Source basis
- Built forward from HC2426.zip / v0.24.26.
- Preserves the confirmed v0.24.24 PS3-user, Steam-population, and shared Library/Shelf-artwork fixes.
- Preserves v0.24.25 PS3/Xbox 360 crash containment and v0.24.26 native driver management.

Shell / navigation validation
- HuymaierShellRedesign.ps1 is present, installer-copied, and bootstrap-preflight parsed.
- Quick Access visible entries are Home, Games, Apps, Downloads, Settings, and Power only.
- Quick Access position is persisted as Bottom/Top/Left/Right with Bottom default.
- Home actions and the three requested horizontal rails are wired.
- Home installed-game validation rejects missing filesystem-backed game/ROM targets before Recent Games / Random Picks render.
- Apps contains Add App, Web Browser, File Browser, custom apps, and Windows-registered apps while filtering known storefront launchers.
- Downloads renders active worker progress/ETA and local recent-completion history; Windows Update is no longer exposed there.
- Settings root exposes Display, Audio, Bluetooth/Wi-Fi, Controllers, Huymaier Console, and Updates. Browser selection/launch mode and FPS counter are not exposed by the v0.25 Settings definition.

PC storefront vs emulator boundary
- Get-GameHubPlatforms adds all implemented PC storefront definitions even when missing and excludes legacy Custom/Generic/HES root cards.
- Installed PC storefront selection exposes Shelf / Library / Manage; missing PC storefront selection exposes Install / Find Installation.
- Storefront Manage exposes Open, provider account integration where implemented, Refresh Library & Artwork, Library Locations / Import, Find Installation, and Uninstall.
- HuymaierEmulatorPlatforms.ps1 is intentionally loaded AFTER HuymaierShellRedesign.ps1.
- Its final platform-select wrapper still calls Start-HcEmulatorPlatform immediately when Test-HcEmulatorPlatform matches, so emulator console cards preserve native direct-entry and do not enter the PC storefront hub.

Artwork validation
- HuymaierArtworkWorker.ps1 writes downloaded artwork only to the supplied Huymaier ArtworkCache directory/result/state files.
- Filename/title normalization is in-memory only; no Rename-Item/Move-Item operation targets a user's game/ROM path.
- Shared ArtworkCache/artwork-index.tsv supports cross-view cached cover reuse.
- Existing/local art, shared index, compatible ES-DE media, provider/platform sources, existing Libretro/GOG/Steam/Wikipedia fallbacks, and final online image search are ordered as non-destructive resolution stages.
- Native Original Xbox/Xbox 360 cover lookup consults the shared Huymaier artwork index before its dashboard-local fallback.

Static validation performed in build environment
- 20 top-level PowerShell source files passed string/comment/here-string-aware delimiter validation.
- 8 C# source files passed string/comment-aware delimiter validation.
- 22 packaged JSON files parsed successfully.
- 1 packaged XML manifest parsed successfully.

Environment limitation
- This Linux packaging environment does not provide Windows PowerShell 5.1, WPF/COM, Windows Update Agent, PnPUtil, WebView2, or the target .NET Framework C# compiler/runtime.
- The Windows installer performs PowerShell preflight/native compilation on the target PC, so v0.25.0 remains a Windows test candidate until installed and exercised on the target system.
