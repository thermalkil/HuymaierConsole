Huymaier Console v0.24.18
DuckStation PS1 Cover Import Fix

FIXED
- Imports existing PlayStation 1 cover art directly from DuckStation's configured/default Covers directory.
- Reads DuckStation cache/gamelist.cache metadata to recover each disc path, serial and title.
- Matches covers in DuckStation's own priority order: serial, disc filename, DuckStation title, then Huymaier title.
- Repairs missing cover paths while opening the cached PS1 library; no full game-folder scan or online artwork worker is started.
- Searches configured cover/cache folders as well as portable and standard default locations.

PRESERVED
- PS1 Original and Updated shell styles.
- All v0.24.17 platform-specific interfaces, startup videos and emulator integrations.
- Existing library/provider refresh rules and persistent artwork behavior.

INSTALL
Extract to C:\HC2418 and run Install-HuymaierConsole.cmd.
