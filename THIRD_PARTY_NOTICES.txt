Artwork discovery / compatibility
- Huymaier Console contains an independently implemented artwork resolver. It does not rename or modify the user's game/ROM files.
- It can consume compatible artwork already present in ES-DE downloaded_media folders and can query public/provider/platform artwork sources at runtime.
- ES-DE custom-cover/media tooling, game-art-downloader projects, Xbox artwork scraper projects, and FindRomCover were evaluated as workflow/reference material while designing the resolver. No source code from those projects is bundled in this archive.
- No FindRomCover GPL source code is copied, linked, or embedded in Huymaier Console.
- Existing Libretro thumbnail lookup remains an optional runtime fallback for supported systems.
- A final unresolved-title fallback can query an image search engine for likely front-cover images. Retrieved artwork is cached in Huymaier Console's own local data area; it is not written into the user's ROM/game files.
- Artwork and game imagery remain the property of their respective rightsholders/contributors. External artwork services and projects are not affiliated with Huymaier Console.
