Huymaier Console v0.25.2 — Settings / Downloads / Input Stabilization

FIXED
- Windows Update and Driver Updates are no longer dead Settings actions. Each opens its own Huymaier Console page, scans automatically, shows found/not-found status, exposes install actions, and offers Restart PC when required.
- Quick Access Location now opens a centered controller-friendly Bottom / Top / Left / Right chooser and persists the selection.
- Mouse hover no longer hijacks controller scrolling just because a stationary cursor happens to sit over content that moved underneath it.
- Native PlayStation HID routing distinguishes PS/Guide from Options: PS/Guide requests global Huymaier Quick Access; Options stays local.
- Apps rechecks Windows app entries against the current installed Games catalog and excludes Steam game shortcut registrations and known game launch protocols.
- Epic installed-library scanning now requires a runnable LaunchExecutable and rejects Marketplace/Vault/Engine/Plugin content. Direct Epic catalogs receive the same defensive filtering, with a schema-4 cleanup rescan on upgrade.
- Downloads records only successful Install completions. Refresh, Scan, Uninstall, Move, login, and pre-existing installed games do not enter history. History retains seven days, caps at twenty newest entries, and removes old bogus Refresh records.
- Recent direct-provider install completions can be backfilled from the last seven days of Huymaier provider logs so downloads completed shortly before this update can still appear.

PRESERVED
- PS3 RPCS3 user selection/profile launch identity.
- Native Steam game population.
- Shared Library/Shelf artwork resolution.
- Native emulator platform direct-entry behavior.
- v0.25 shell structure, driver worker, artwork resolver, and crash containment.
