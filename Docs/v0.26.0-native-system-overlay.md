# Huymaier Console v0.26.0 native system overlay

This branch replaces Windows/Xbox controller overlay behavior with Huymaier-owned native UI while keeping the in-console Quick Access surface separate.

## Guide button contract

- While Huymaier Console is foreground, the physical Guide / Xbox / PS / Home system button opens Huymaier Quick Access.
- While an external game or app is foreground, the same physical system button opens the Huymaier Game Bar.
- Xbox View/Back and PlayStation Share/Create are not aliases for Guide and must never open Quick Access or the Game Bar.
- Menu/Start/Options remain distinct local buttons.

## Quick Access

Quick Access exists only inside Huymaier Console. It contains Home, Games, Apps, Downloads, Settings, and Power and preserves its configurable Bottom / Top / Left / Right placement.

## Huymaier Game Bar

The Game Bar is a separate always-on-top native overlay for external games/apps. Initial pages are:

- Game Bar home: Resume, Switch Apps, Return to Huymaier Console, Close Current App.
- Switch Apps: controller-native task switching between user-facing top-level Windows applications.

Planned follow-up pages are Audio, Capture, Performance, and Controller status. These must be implemented as Huymaier-native surfaces rather than opening Xbox Game Bar or the Windows task switcher.

## Xbox Game Bar coexistence

The Huymaier Game Bar disables the per-user Windows/Xbox Game Bar controller/system-button activation and capture toggles it replaces. The Microsoft package itself is not uninstalled. Original values are backed up under Huymaier Console local application data so the suppression can be reversed later.

## Footer prompt contract

Controller prompts are capabilities, not decoration. A prompt is visible only if its button has a real handler in the current context.

- Never show a global `X / Square = Search` placeholder.
- Show `X / Square = Manage` only when the selected game/storefront can actually enter Manage.
- Show `X / Square = Install` only when the selected storefront can actually be installed.
- Physical Guide / PS / Home is labeled `Quick Access` inside Huymaier Console.
