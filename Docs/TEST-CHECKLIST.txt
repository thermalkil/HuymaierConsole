Huymaier Console v0.25.6 Test Checklist

1. Fresh/empty-profile startup
- Install on a PC/user with no Huymaier Console history.
- Confirm Home renders with empty recent rails and no .Count startup failure.

2. Centered option choosers
- Settings -> Huymaier Console -> Quick Access location. Confirm Bottom / Top / Left / Right appear together.
- Keyboard Theme. Confirm Huymaier / Light / High Contrast appear together and selection changes keyboard palette.
- Button Prompts. Confirm all prompt families appear together.
- Music Theme. Confirm available themes appear together; Custom appears only when custom music exists.
- Verify D-pad/arrow navigation, A/Enter apply, B/Back cancel.

3. Display scale
- Settings -> Display -> Scale. Confirm percentage popup opens.
- Select a different percentage. Confirm the page reports current -> configured scale until Windows sign-out.
- Confirm Sign out to apply display scale requires confirmation.
- After sign-in, confirm Windows and Huymaier Console use the selected scale.

4. Regression locks
- Steam library population.
- RPCS3 user discovery.
- Shelf uses Library artwork.
- Epic library excludes Unreal Engine assets.
- Epic download card shows progress, downloaded/total, rate and ETA.
- GitHub updater can check public thermalkil/HuymaierConsole Releases without authentication.
- Windows Update and Driver Updates open their own pages.
