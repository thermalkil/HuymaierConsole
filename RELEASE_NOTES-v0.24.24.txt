Huymaier Console v0.24.24

STEAM LIBRARY RESTORATION + SHARED SHELF ARTWORK

Steam
- Restores native Steam game discovery from every detected Steam library and every configured Steam root.
- Reads installed games from Steam appmanifest_*.acf records and launches them through steam://rungameid/<appid>.
- Steam games once again appear as individual titles inside Huymaier Console instead of Steam being represented only by Big Picture.
- Steam Big Picture remains a separate optional platform mode and is never inserted as a fake library game.
- Steam cover art first reuses Steam's own library cache/custom grid artwork, then the existing Huymaier artwork worker can fill missing covers online.
- Filters common Steam infrastructure/tool manifests such as Steamworks Common Redistributables and dedicated-server/SDK entries.
- v0.24.24 bumps the storefront-library schema so upgrades from v0.24.23 automatically perform one corrective background rescan. No manual rescan should be required after the first launch.

Shelf artwork
- Shelf no longer trusts an independent installed-game artwork cache.
- Every installed Shelf entry is hydrated/merged against the matching Library record before rendering.
- Cover art and hero art therefore come from the same resolved paths used by Library, while Shelf keeps the installed game's direct launch target and install path.
- Persistent platform indexes are bumped to schema 2 so stale v0.24.23 shelf records are discarded automatically.

Preserved
- PS3 RPCS3 user-profile discovery/selection from dev_hdd0\home\00000001, 00000002, and onward.
- PS3 installed-theme switching.
- Native Xbox and Xbox 360 dashboards and online cover-art cache.
- Steam Big Picture background behavior: Huymaier Console remains running and ignores controller navigation while unfocused.
- Console library-count background reconciliation.

Steam owned-library note
- This build restores the complete locally installed Steam collection from the Steam client itself. Valve's official owned-games Web API requires a Web API key, so v0.24.24 does not invent uninstalled ownership from undocumented Steam cache files. A future authenticated Steam-owned-library source can merge uninstalled titles into the same Library model without changing Shelf behavior.

Validation
- PowerShell files received structural delimiter/string/comment checks in the build environment.
- JSON and XML payloads were parsed.
- Package checksums and ZIP integrity are generated/verified before handoff.
- The Windows WPF application still cannot be compiled or executed in this Linux environment, so this remains a Windows test candidate.
