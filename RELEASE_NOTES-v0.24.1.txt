Huymaier Console v0.24.1

INSTALLER / NATIVE COMPILE FIX
- Fixes the v0.24.0 C# compile failure caused by the PS2 Raw Input hook calling a nonexistent RawHidController.HandleWindowMessage method.
- The PlayStation 2 window now routes WM_INPUT and WM_INPUT_DEVICE_CHANGE through the same tested ProcessInput and ProcessDeviceChange methods used by the PS3 XMB.
- The obsolete FormattedText messages remain warnings only and do not block installation.

PLAYSTATION 2 PLATFORM
- Preserves the first native PS2 platform implementation from v0.24.0.
- Adds PS2 under Games > Platforms and opens an in-process PlayStation 2 interface backed by PCSX2.
- Uses the PSBBN/HDD-OSD-inspired channel and Game Collection presentation while retaining PlayStation 2 branding.
- Preserves existing/managed PCSX2 setup, BIOS, libraries, native settings, memory cards, saves, screenshots, media, patches, cheats, widescreen fixes, textures, maintenance, and safe return.

PS3 FIRMWARE THEMES
- Adds Settings > Theme Settings > Firmware Themes.
- Scans the selected RPCS3 data location at dev_flash\vsh\resource\theme for firmware-bundled .p3t themes.
- Lists every discovered bundled theme as a selectable native XMB option.
- Keeps Original PS3 (Firmware Default) as a separate stock presentation using the time/month color field and firmware assets.
- Imports a selected firmware theme into Huymaier's private XMB cache only; RPCS3 and dev_flash are never modified.
- Reuses the selected firmware font, theme icons, backgrounds, and compatible sounds.
- Re-imports a cached firmware theme only when its source file changes.
- Adds Refresh Firmware Theme List after firmware installation or RPCS3 data-path changes.
- Preserves external .p3t installation, Huymaier Default, Custom Folder, custom background color, and per-theme color preferences.

PRESERVED BASELINE
- Preserves v0.23.8 controller hot-plug, relaunch, RPCS3 launch, PS3 detection/deduplication, native saves/trophies/settings/photos, GOG stability, and shelf artwork fixes.

Windows compilation and physical PCSX2/RPCS3/controller testing still occur on the target Windows 11 system during installation.
