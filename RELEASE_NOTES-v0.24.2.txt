Huymaier Console v0.24.2
PSBBN UI + Saved-Data Geometry + PCSX2 Cover Art

PS2 INTERFACE REBUILD
- Replaces the modern top-tab/carousel shell with a PlayStation BB Navigator-style presentation.
- Adds the PlayStation BB header, thin divider lines, yellow section headings, cyan menu text, soft selection glow, dark star field, and PlayStation-style confirm/back prompts.
- Restores a PSBBN-style Top Menu. Up/down chooses a channel, Cross/confirm opens it, and Circle/back returns one level.
- Game Collection keeps the useful cover-flow behavior from the PSBBN Definitive Project model but removes the modern rounded-card styling.

SAVED-DATA BACKGROUND
- Background geometry is now deterministic and derived from the user's PCSX2 memory-card data instead of random decorative waves.
- Folder memory cards create one data structure per saved-data folder, with height influenced by save size and freshness.
- Raw .ps2/.mcd/.mc2/.bin memory cards are sampled safely and read-only; occupied data regions determine the number and height of translucent PS2-style structures.
- The background refreshes when the PS2 interface opens, when memory cards are refreshed, after PCSX2 returns, and when the PCSX2 data location changes.

PCSX2 COVER ART
- Reuses cover art already downloaded by PCSX2.
- Searches the active PCSX2 data folder, portable install folder, configured install folder, and standard Documents/AppData/LocalAppData PCSX2 cover folders.
- Matches PCSX2 serial naming variants as well as normalized game filenames and titles.
- When a game filename has no serial, reads a small portion of ISO/BIN/IMG/MDF/NRG disc headers to recover the serial used by PCSX2 cover filenames.

PRESERVED BASELINE
- Based directly on v0.24.1 and preserves its native compile fix.
- Preserves the stable v0.23.8 PS3/controller/GOG/shelf/save/relaunch fixes and the v0.24.1 PS3 firmware-theme/custom-color work.
- PCSX2 installation detection behavior is otherwise unchanged in this UI-focused pass.

TESTING
- The package received source-structure, manifest, installer, checksum, and archive validation in the build environment.
- Native Windows compilation and physical PCSX2/controller testing still occur on the target Windows 11 system during installation.
