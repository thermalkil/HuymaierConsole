Huymaier Console v0.24.5
PlayStation 2 Saved Data, Audio, Alphabet Index and PCSX2 Overlay

INTERFACE
- Removes the redundant Top Menu heading.
- Removes Collection and Disc labels from Game Channel.
- Adds a #-Z index on the left side of Game Channel. Press Up to focus it, Up/Down to select a letter, and Cross to jump. L1/R1 jumps between populated letters.

MEMORY CARDS
- Selecting a card now opens its saved-data grid instead of only showing card utilities.
- Folder memory cards show individual saves with icon.sys titles, size, file count and modification time.
- Standard PCSX2 .ps2 file memory cards are parsed read-only and show their actual save directories, icon.sys titles, size, file count and free space.
- Triangle opens save/card options. File-card saves can be exported safely to a folder.
- Open in Original PS2 Browser boots the real BIOS Browser through PCSX2 for authentic copy/delete management.

AUDIO
- Adds PlayStation 2 Interface Audio settings.
- Import one background-music track and custom Navigate, Confirm and Back sound effects.
- Adds independent enable switches and 0/25/50/75/100 percent volume controls.

PCSX2 OVERLAY
- Games launch with PCSX2 Big Picture enabled by default, preserving the controller pause menu for save/load state, settings and exit.
- The overlay can be disabled in PS2 System Settings.

PRESERVED
- Keeps the v0.24.4 PCSX2 launch fix, cached library, PCSX2 covers, PS3 features and v0.23.8 stabilization fixes.
