Huymaier Console v0.24.10
PS2 Save Textures, Fullscreen Return and Main-Menu Return Fix

PS2 MEMORY-CARD SAVE ICONS
- Applies each save icon's embedded 128x128 texture to the animated 3D model using the actual per-vertex UV coordinates.
- Replaces the previous one-color-per-triangle approximation with clipped affine texture mapping.
- Keeps animated shape interpolation, depth sorting, vertex transparency and face lighting.
- Corrects compressed icon texture decoding: literal runs begin at 0xFF00, not 0x8000.
- Tolerates alignment padding and icons whose texture flags are incomplete or nonstandard.
- Falls back to vertex-color rendering only when a save truly has no usable texture.

EMULATOR RETURN / FULLSCREEN
- Native window activation now preserves a requested maximized borderless window instead of calling SW_RESTORE and dropping it to a desktop-sized window.
- Applies when returning from PCSX2, RPCS3 and other hosted console views.
- After a PS2 game closes, Huymaier Console returns to the PlayStation 2 main menu in true fullscreen.
- Controller/keyboard focus, menu audio, save-data refresh and input state are restored after PCSX2 exits.

PRESERVED
- Global Xbox/controller hot-plug stabilization.
- PCSX2 Big Picture game launch and Cross/A/Enter-only launch input.
- Native PS2 memory-card browsing and save actions.
- PS2 boot skyline, startup/menu/game-selection audio and PS3 ambience.

REFERENCE POLICY
- Public PS2 icon-format documentation and PS2IODB were used as technical references only.
- No third-party save icon database assets or Sony BIOS assets are bundled.
