# v0.26.0 development branch

This branch is intentionally isolated from the v0.25.8 stable release while the native Windows-level Game Bar, task switcher, Guide routing, popup chooser correction, and prompt cleanup are developed.

The branch carries small reviewed patch batches for very large legacy PowerShell/C# files, plus native overlay source files. Windows CI parses the PowerShell source and compiles the native GameInput/overlay components before the branch is considered package-ready.
